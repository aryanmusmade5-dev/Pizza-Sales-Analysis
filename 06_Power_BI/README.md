## 📌 Overview

This folder contains the **Power BI dashboard** built for the **Pizza Sales Analysis** capstone project.

The dashboard turns transactional pizza sales data into interactive business insights, helping management understand:

- 💰 **Sales performance**
- 🍕 **Product performance**
- 🛒 **Customer purchasing patterns**
- 📈 **Sales trends over time**

It is aligned with the project's **Business Requirements Document (BRD)** and supports data-driven decisions on **sales, marketing, menu optimization, inventory, and staffing**.

## 🎯 Business Objective

Give management a single, interactive view of pizza sales performance, covering:

| Area | Metrics / Analysis |
|---|---|
| **Overall performance** | Total revenue, total orders, total pizzas sold |
| **Order behaviour** | Average Order Value (AOV), average pizzas per order |
| **Product mix** | Sales by category and by size |
| **Product ranking** | Best-selling and least-selling pizzas |
| **Time patterns** | Sales trends by day and by time of day |

---

## 🗂️ Data Source

**Source file:** `pizza_sales.csv` — transactional pizza sales records (48,620 rows, 12 columns).

### Key Fields

| Field | Description |
|---|---|
| `order_id` | Identifier for the customer order |
| `pizza_id` | Identifier for the pizza |
| `pizza_name` | Name of the pizza |
| `quantity` | Number of pizzas sold |
| `order_date` | Date of the order |
| `order_time` | Time of the order |
| `unit_price` | Price per pizza |
| `total_price` | Revenue generated by the transaction |
| `pizza_size` | Pizza size |
| `pizza_category` | Pizza category |
| `pizza_ingredients` | Ingredients used in the pizza |

---

## 📌 Key Performance Indicators

All KPIs follow the definitions in the project's BRD.

| KPI | Definition | Formula |
|---|---|---|
| 💰 **Total Revenue** | Sum of `total_price` | `SUM(total_price)` |
| 🍕 **Total Pizzas Sold** | Sum of `quantity` | `SUM(quantity)` |
| 🧾 **Total Orders** | Count of unique `order_id` | `DISTINCTCOUNT(order_id)` |
| 💵 **Average Order Value (AOV)** | Total Revenue ÷ Total Orders | `Total Revenue / Total Orders` |
| 📦 **Avg. Pizzas per Order** | Total Pizzas Sold ÷ Total Orders | `Total Pizzas Sold / Total Orders` |

## 📊 Report Pages

### 🏠 Page 1 — Home

The primary management dashboard, giving a complete overview of business performance.

**Includes:**

- KPI cards (revenue, orders, pizzas sold, AOV, pizzas per order)
- Revenue and quantity by **pizza category**
- Revenue and quantity by **pizza size**
- **Sales trends** by day and time
- Overall order and volume performance

### 🏆 Page 2 — Best / Worst Sellers

A product-level view of pizza performance.

**Helps identify:**

- Best-selling (top-performing) pizzas
- Least-selling (bottom-performing) pizzas
- Product-level revenue and quantity performance

**Supports:** menu optimization, promotional planning, and decisions on underperforming products.

## ⚠️ Data & Interpretation Notes

- The dashboard is based on **transactional pizza sales data**.
- **Revenue** represents `total_price` from the dataset.
- Revenue is **not profit** — the dataset has no complete cost information.
- KPI definitions follow the project's BRD.
- The dashboard is intended for **descriptive** business-performance analysis.
- Findings should be interpreted within the context of the available data.

---

## 🚀 How to Open the Dashboard

1. Install **Power BI Desktop** (free, Windows).
2. Download or clone this repository.
3. Open `Pizza Sales Dashboard.pbix`.
4. If prompted, update the data source path to the location of `pizza_sales.csv` (`02_Data/Raw/`) via **Transform Data → Data source settings**.
5. Click **Refresh** to reload the data.
