# 📘 2. Data Dictionary

This document explains every column in the **Pizza Sales** dataset used in this project.

---

## 📊 Dataset Overview

| Item | Details |
|------|---------|
| 📁 **Source files** | `pizza_sales.csv`, `pizza_sales_excel_file.xlsx` (sheet: `pizza_sales`) |
| 🧾 **Number of rows** | 48,620 (each row = one pizza line item in an order) |
| 🧱 **Number of columns** | 12 |
| 📅 **Time period** | 01-01-2015 to 31-12-2015 (one full year) |
| 🛒 **Unique orders** | 21,350 |
| 🍕 **Unique pizza types** | 32 pizza names (91 name + size combinations) |
| 📦 **Total quantity sold** | 49,574 pizzas |
| 💰 **Total revenue** | 817,860.05 |
| ✅ **Missing values** | None – all 12 columns are fully populated |

> 📌 **Grain of the data:** One row represents one pizza (name + size) within an order. A single order can have several rows, so `order_id` repeats.

---

## 🗂️ Column Descriptions

| # | Column | Data Type | Meaning | Example |
|---|--------|-----------|---------|---------|
| 1 | `pizza_id` | Integer | Unique identifier for each row (line item). Runs from 1 to 48,620 and never repeats – this is the primary key. | `1` |
| 2 | `order_id` | Integer | Identifier of the customer order. Multiple rows can share the same `order_id` when a customer orders more than one pizza. | `2` |
| 3 | `pizza_name_id` | Text | Short code for the pizza **and its size** (format: `pizza_code_size`). | `hawaiian_m` |
| 4 | `quantity` | Integer | Number of pizzas ordered in that line item. Values range from 1 to 4. | `1` |
| 5 | `order_date` | Date | Date on which the order was placed. In the CSV it is stored as text in `DD-MM-YYYY` format; in the Excel file it is a proper date. | `01-01-2015` |
| 6 | `order_time` | Time | Time of day the order was placed (24-hour `HH:MM:SS`). Ranges from about 09:52 to 23:05. | `11:38:36` |
| 7 | `unit_price` | Decimal | Price of one pizza of that size. Ranges from 9.75 to 35.95. | `13.25` |
| 8 | `total_price` | Decimal | Total sales amount for the line item. Calculated as `quantity × unit_price`. | `13.25` |
| 9 | `pizza_size` | Text | Size of the pizza: `S` (Small), `M` (Medium), `L` (Large), `XL` (Extra Large), `XXL` (Double Extra Large). | `M` |
| 10 | `pizza_category` | Text | Menu category of the pizza: `Classic`, `Supreme`, `Veggie`, `Chicken`. | `Classic` |
| 11 | `pizza_ingredients` | Text | Comma-separated list of ingredients used in the pizza. | `Sliced Ham, Pineapple, Mozzarella Cheese` |
| 12 | `pizza_name` | Text | Full display name of the pizza (without size). | `The Hawaiian Pizza` |

## 🔗 Key Relationships & Rules

- 🔑 `pizza_id` is unique for every row (primary key).
- 🔁 `order_id` is **not** unique – one order can contain many rows.
- 🧮 `total_price = quantity × unit_price` holds true for every row in the dataset.
- 🍕 Each `pizza_name` always has the same category and the same ingredient list.
- 🧩 `pizza_name_id` = pizza code + size, so it is more granular than `pizza_name` (91 values vs 32).

---

## 🧹 Data Quality Notes

- ✅ No null or missing values were found in any column.
- 📅 `order_date` is text (`DD-MM-YYYY`) in the CSV, so it must be converted to a date type before time-based analysis (monthly trends, weekday analysis, etc.). The Excel file already stores it as a date.
- ⏰ `order_time` is stored as text in the CSV and as a time value in Excel; extract the hour for peak-hour analysis.
- 💱 The dataset does not state a currency, so values are treated as plain currency units.
- 🥬 `pizza_ingredients` holds several values in one cell, so it needs to be split if you want ingredient-level analysis.

## 🛠️ Useful Derived Columns (created during analysis)

| Derived Column | How it is created | Used for |
|----------------|-------------------|----------|
| `order_month` | Month extracted from `order_date` | 📈 Monthly sales trend |
| `order_weekday` | Day name extracted from `order_date` | 📆 Busiest days |
| `order_hour` | Hour extracted from `order_time` | ⏱️ Peak hours |
| `revenue` | Same as `total_price` | 💵 Revenue KPIs |
| `avg_order_value` | Total revenue ÷ distinct `order_id` | 🧾 Average Order Value (AOV) |
