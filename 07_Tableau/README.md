## 📌 Overview

This folder contains the **Tableau dashboard** built for the **Pizza Sales Analysis** capstone project.

The workbook turns transactional pizza sales data into interactive visualizations that help management understand:

- 💰 **Sales performance**
- 🍕 **Product performance**
- 🛒 **Customer purchasing patterns**
- 📈 **Sales trends over time**

It is aligned with the project's **Business Requirements Document (BRD)** and supports decisions on **sales, marketing, menu optimization, inventory, and staffing**.

## 🎯 Business Objective

Provide an interactive view of pizza sales performance and convert transactional data into useful business information.

| Area | Metrics / Analysis |
|---|---|
| **Overall performance** | Total revenue, total orders, total pizzas sold |
| **Order behaviour** | Average Order Value (AOV), average pizzas per order |
| **Product mix** | Sales by pizza category and by size |
| **Time patterns** | Monthly sales trends, hourly order trends |
| **Product ranking** | Best-selling and least-selling pizzas |

## 🗂️ Data Source

**Source file:** `pizza_sales.csv` — transactional pizza sales records (48,620 rows, 12 columns).

### Key Fields

| Field | Description |
|---|---|
| `pizza_id` | Identifier for the pizza record |
| `order_id` | Identifier for the customer order |
| `pizza_name_id` | Identifier for the pizza type |
| `quantity` | Number of pizzas sold |
| `order_date` | Date of the order |
| `order_time` | Time of the order |
| `unit_price` | Price per pizza |
| `total_price` | Revenue generated by the transaction |
| `pizza_size` | Pizza size |
| `pizza_category` | Pizza category |
| `pizza_ingredients` | Ingredients used in the pizza |
| `pizza_name` | Name of the pizza |

---

## 📌 Key Performance Indicators

All KPIs follow the definitions in the project's BRD.

| KPI | Definition | Tableau Logic |
|---|---|---|
| 💰 **Total Revenue** | Sum of `total_price` | `SUM([total_price])` |
| 🍕 **Total Pizzas Sold** | Sum of `quantity` | `SUM([quantity])` |
| 🧾 **Total Orders** | Count of unique `order_id` | `COUNTD([order_id])` |
| 💵 **Average Order Value (AOV)** | Total Revenue ÷ Total Orders | `SUM([total_price]) / COUNTD([order_id])` |
| 📦 **Avg. Pizzas per Order** | Total Pizzas Sold ÷ Total Orders | `SUM([quantity]) / COUNTD([order_id])` |

## 📊 Dashboards

The workbook contains **two dashboards**.

### 🏠 Dashboard 1 — Home

The main management overview of pizza sales performance.

**Includes:**

- KPI banner (revenue, orders, pizzas sold, AOV, pizzas per order)
- % of sales by pizza category
- Total orders and quantity sold by category
- Orders trend by hour
- Orders by month
- Date range context

### 🏆 Dashboard 2 — Best / Worst Sellers

A product-level view of pizza performance.

| Ranking | By Revenue | By Orders | By Quantity |
|---|:---:|:---:|:---:|
| **Top 5 pizzas** | ✅ | ✅ | ✅ |
| **Bottom 5 pizzas** | ✅ | ✅ | ✅ |

**Supports:** menu optimization, marketing and promotional planning, and decisions on underperforming products.

## ⚠️ Data & Interpretation Notes

- The dashboards are based on **transactional pizza sales data**.
- **Revenue** represents `total_price` from the dataset.
- Revenue is **not profit** — the dataset has no complete cost information.
- KPI definitions follow the project's BRD.
- The dashboards are intended for **descriptive** business-performance analysis.
- Findings should be interpreted within the context of the available data.

## 🚀 How to Open the Workbook

1. Install **Tableau Desktop** or the free **Tableau Public** desktop app.
2. Download or clone this repository.
3. Open `Pizza Sales.twbx`.
4. Use the dashboard tabs (**Home** and **Best / Worst Sellers**) at the bottom of the window.

> 💡 No data setup is needed. The `.twbx` is a packaged workbook with its data included.
